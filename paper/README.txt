SmartFish IEEE Conference Paper — LaTeX source
================================================

Files
-----
main.tex          - the paper (IEEEtran conference format)
references.bib    - BibTeX references (9 real, verified sources)
figures/          - confusion matrix + ROC curves, generated by
                    src/evaluate.py from the actual trained checkpoint
main.pdf          - already-compiled PDF, included for convenience

Before you submit
------------------
Open main.tex and fill in the TODO near the top (search for "TODO"):
  - Your name
  - Department / college / university
  - City, country
  - Email address

Everything else (abstract, all numbers, tables, figures, references)
is real content pulled directly from this project — nothing in the
body of the paper needs to be invented. If your guide/department
wants an "Acknowledgment" section (thanking your guide, HOD, etc.),
add one before \bibliographystyle{IEEEtran} — that's the one part
that's genuinely up to you to write.

How to compile
---------------
Option 1 (recommended) — Overleaf:
  1. Go to overleaf.com, create a new project, "Upload Project".
  2. Upload this whole folder as a zip.
  3. Set the compiler to pdfLaTeX (Menu > Compiler, if not already).
  4. Click Recompile. IEEEtran.cls is built into Overleaf, so it
     just works.

Option 2 — local compile (needs a LaTeX distribution: TeX Live or
MiKTeX; IEEEtran.cls is bundled with both, so nothing extra to
install):
  pdflatex main.tex
  bibtex main
  pdflatex main.tex
  pdflatex main.tex
(bibtex + a 2nd/3rd pdflatex pass are needed to resolve the
reference numbers and in-text citation callouts correctly.)

Where the numbers came from
-----------------------------
All results in Section IV (97.18% accuracy, macro F1 0.76, the
per-class table, the confusion matrix, the ROC curves) come from
running src/evaluate.py against models/best_model.pt on the
780-image held-out test set — not estimated or reused from memory.
Re-run `python src/evaluate.py` from the project root at any time
to regenerate results/metrics.json and the two figures if you
retrain the model.

The related-work citations (references [1]-[9] in the bibliography)
were looked up and verified individually (title/authors/venue/year
confirmed from the publisher page or arXiv) rather than invented —
you can follow the DOI/URL in each .bib entry to check them yourself.
